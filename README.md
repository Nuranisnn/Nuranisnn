### MyVoiceGuard

MyVoiceGuard is my Final Year Project focused on detecting AI-generated (deepfake) audio to help address the growing problem of misinformation and voice impersonation. 

The system applies a hybrid detection framework combining signature-based analysis and machine learning techniques to identify patterns and anomalies in synthetic speech.

The platform allows users to upload audio files through a web interface, where the system analyzes the media and determines whether it is authentic or AI-generated.

For experimentation and model training, I constructed a dataset consisting of real and synthetic voices generated through voice cloning models, including samples inspired by Malaysian political figures such as Anwar Ibrahim, Najib Razak, and Tun Mahathir Mohamad.

The system is developed as a full-stack web application using HTML, CSS, JavaScript, Bootstrap, PHP, and MySQL, with additional Python-based tools used for audio processing and dataset generation.

This project explores how AI can also be used to detect AI-generated media, contributing toward improving digital media authenticity and security.

Skills: HTML · JavaScript · PHP · MySQL · Web Development · Front-End Development · Back-End Web Development · Network Security · Python (Programming Language) · Machine Learning · Fast API
